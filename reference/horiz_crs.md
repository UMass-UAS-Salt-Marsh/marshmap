# Horizontal CRS of a spatial object as `authority:code`

Horizontal CRS of a spatial object as `authority:code`

## Usage

``` r
horiz_crs(x)
```

## Arguments

- x:

  An `sf`, `sfc`, `crs`, `SpatRaster`, or `SpatVector` object, or a CRS
  string

## Value

Horizontal CRS as a string, e.g., `EPSG:6491`
